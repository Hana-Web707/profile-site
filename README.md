# 自己紹介サイト

AIを活用しながら、Next.jsとTailwind CSSで制作した1ページの自己紹介サイトです。

## 主な内容

- 自己紹介、経歴、学習中のスキル
- 制作実績「hair salon LUXE」へのリンク

## 使用技術

- Next.js（App Router）
- TypeScript
- Tailwind CSS

## セットアップと起動

Node.jsをインストールしたWindows環境で、プロジェクトのフォルダーをPowerShellで開きます。次のコマンドを上から順に実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

開発サーバーが起動したら、ブラウザのアドレス欄で `http://localhost:3000` を開きます。
